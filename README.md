*Real-Time Event Orchestration
 EVENTPULSE manages college events as live systems, enabling real-time registrations, updates, and operational control throughout the event lifecycle.

*Secure Authentication & Role Management
 Implements JWT-based authentication with role-based authorization to securely manage students and administrators.

*State-Driven Event Lifecycle
 Events follow enforced states (Created, Registration Open, Live, Completed), ensuring all actions occur only at valid phases.

*Scalable Backend Architecture
 Built with Spring Boot and MySQL using a layered architecture to ensure data integrity, scalability, and clean separation of concerns.

*Modern, User-Friendly Frontend
 Developed using React (TypeScript) with a responsive, icon-driven UI designed to resemble a production-grade SaaS platform.
